# Mengembangkan Drum Companion

1. Gunakan Node.js 20+ dan jalankan `npm start`.
2. Edit halaman di `public/index.html`, tampilan di `public/assets/styles.css`, dan alur app di `public/assets/app.js`.
3. Tempatkan logika ritme tanpa DOM/perangkat di `public/assets/rhythm-core.js`, agar bisa diuji dengan Node.
4. Jalankan `npm run check` dan `npm test` sebelum commit.
5. Periksa manual player Mini/Setengah/Penuh, layar ponsel, serta browser tanpa izin MIDI.

Pertahankan materi berbahasa Indonesia, hitungan yang selaras dengan notasi, dan keterangan yang jujur untuk hasil audio eksperimental. Jangan mengklaim pola latihan sebagai partitur asli lagu tertentu.

Jangan commit file `.env`, rekaman pribadi, token, atau data `localStorage`. Belum ada langkah build, akun pengguna, layanan transkripsi, atau deployment otomatis.
